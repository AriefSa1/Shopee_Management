## Execution rules

- Every unchecked item requires an implementation worker, a failing-first proof where behavior is new, automated verification, a real manual-QA artifact, adversarial probes for applicable classes, and an independent verifier before it becomes complete.
- Phase dependencies are strict. Phase 2 cannot use real external credentials; Phase 6 cannot enable writes until the pre-write gate is confirmed by dated official evidence.
- If the current workspace is not a Git repository, implementation remains local and no PR/branch workflow is claimed.
